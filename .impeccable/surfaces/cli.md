# Agent 自动部署

- Route: /guide/cli
- Mode: Operate
- 用户：已经让 AI 写出项目，需要首次上线、更新已有作品或排查部署错误的普通人。
- 成功：选定任务并说明已有条件，复制一份可执行的 AI 任务，理解自己要配合的操作，并按作品类型亲自验收。
- 保留柔和粉绿、三栏工具布局与现有控件。优先展示任务类型与四项必要情况；预算、商业用途、本地状态与技术知识按需展开。
- 不假设 AI 能操作电脑；普通聊天工具输出逐步手动指导。未知作品与平台先检查，不能强行把小程序、客户端或脚本当网站。
- 更新沿用现有项目与数据，排错携带真实操作与脱敏日志；输入不持久化、不提交服务端。修改条件或目标平台时清空生成结果与验收记录。
- 生成后滚动并聚焦结果标题；复制有成功反馈。验收清单按作品、任务和数据需求调整。
- 九类 CLI 工具保留原搜索深链接；命令组默认折叠，每行独立复制并解释用途与成功表现。GitHub 保存代码、网站发布和数据库迁移分别说明；Prisma 命令明确限定 ORM 7。
- 视觉验收由用户负责。自动检查任务分支、复制、键盘、平台深链接、重置与移动端溢出，不截图。
