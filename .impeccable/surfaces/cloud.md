# 云端部署平台

- Route: /guide/cloud
- Mode: Operate
- 用户：已经用 AI 做出项目、不知道如何选择托管平台与预算的普通人。
- 成功：按现有项目找到兼容候选，区分持续额度、限期试用和资格限制，比较费用、休眠与数据保存方式，再携带条件进入部署任务。
- 保留粉绿主题、三栏工具系统；知识默认折叠，选型与平台浏览优先。
- 未知技术先复制项目检查任务，本地工具不强行上云，客户端与后端明确区分。
- 候选复用启动器平台排序和适配数据，增加预算与商业条件过滤。Vercel Hobby 不进入商业免费候选，Railway Free 不作为 Cron 方案，试用不冒充持续免费。
- 平台每页六项，多关键词、分类与持续免费筛选可以组合；搜索深链接清除筛选并打开所在页。已移出推荐的平台不在页面和全站搜索中展示，历史状态仅保留在内部数据中。
- 数据服务选择当场显示四种下一步：先检查、跳过、先准备、沿用已有服务，明确说明会带入部署任务。
- 最多同时比较三个平台，跨页保留选择；表格仅在自身区域横向滚动。复制比较任务只包含已选候选。
- 跳转 Agent 页面带平台、作品类型、用途、预算、数据状态。URL 仅含固定选项，目标页校验允许值。
- 官方依据保存在 platform-reviews.json；页面展示费用条件和官方链接，不展示内部核验状态。
- 视觉验收由用户负责；自动检查候选、筛选、分页、复制、深链接、比较上限、键盘与手机溢出。
